# Forkify

Forkify is a recipe creation and storage JavaScript application. It allows users to search for ingredients and dishes, create recipes, and store them for future reference. This project was developed as part of the JS Mastery class.

## Description

Forkify is built using pure JavaScript, CSS, and HTML, offering a refreshing and straightforward approach to web development without relying on heavy frameworks. It utilizes modern JavaScript features and tools to provide a seamless user experience.

## Live Demo

Check out the live demo of Overfork on Netlify: [Overfork Live](https://overfork-overton.netlify.app)
